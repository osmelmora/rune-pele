# Security

rune-pele parses Mermaid source that apps often take from users or language models, so a source that crashes the parser, hangs it, or makes it use unbounded memory is a security bug.

Report one privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**. Do not open a public issue for it. Include the source that shows it and the version or commit you ran.

Fixes go into the newest release only.
